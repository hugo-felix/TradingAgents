# StockSeek identity assets

The selected source artwork was generated in Jimeng and supplied/approved by the user on 2026-11-06. The application uses this exact bull/bear S composition, with technical extraction, optical centering and consistent padding. This artwork was not generated by the unsuccessful OpenAI API request in the session.

- `source/stockseek-original.png`: unmodified selected 2048×2048 source.
- `stockseek-mark.png`: cropped ivory mark with genuine alpha for interface use.
- `app.png`: 1024×1024 app icon, with transparent corners.
- `app.icns`: macOS size variants.
- `app.ico`: Windows 16/24/32/48/64/128/256 variants.
- `icon-*.png`: generated locally for verification and reuse; excluded from version control. The packaged interface icon is kept in `tradingagents/desktop/static/`.

Rebuild these assets with `python desktop/generate_icons.py` (Pillow required only for this development task). Copy `stockseek-mark.png` and `icon-128.png` into `tradingagents/desktop/static/` as `stockseek-mark.png` and `stockseek-icon.png` if changing the source again. All builds retain the previous app identifier and workspace directory so renaming the display does not reset local data or credentials.
