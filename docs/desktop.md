# StockSeek桌面工作台

StockSeek在当前 TradingAgents 引擎上提供本地桌面界面，面向 macOS 与 Windows。首页关注研究更新，股票档案按“研究摘要 / 事实与依据 / 我的判断 / 完整报告”组织信息。

侧栏“书籍资料”支持填写元数据后选择 PDF / EPUB 登记、查看版本和来源详情、核验本地原文快照；登记后可手动解析本地文本、选择解析版本、按关键词检索并展开完整位置与出处。登记不启动解析、索引或模型请求；文本解析不包含 OCR、图表、公式或语义检索。“策略管理”支持录入适用范围与七类规则、保存草稿、核对历史版本和具名确认，并按版本读取外部运行证据；确认及外部登记均不代表已实现或通过回测。运行证据目前通过本地 API 登记，不提供回测执行入口。页面操作、接口、原文快照、完整性核验及备份范围见[策略与书籍登记基础](strategy-knowledge.md)。

## 从源码启动

Python 3.11 或更高版本，在仓库根目录运行：

```sh
pip install ".[desktop,a-shares]"
python -m tradingagents.desktop
```

也可使用安装后生成的 `tradingagents-desktop` 命令。当前仓库已有虚拟环境时：

```sh
.venv/bin/python -m tradingagents.desktop
```

Windows 对应 `\.venv\Scripts\python.exe -m tradingagents.desktop`。

可选启动参数：

```sh
python -m tradingagents.desktop --data-dir ./output/my-workspace --import-reports ./artifacts --env-file .env
```

`--data-dir` 为独立工作空间，默认 `~/.tradingagents/desktop`；也可设置 `TRADINGAGENTS_DESKTOP_DIR`。同一工作空间只允许一个应用实例。运行期间不要用其他程序改写其数据库。

## 使用

今日关注显示“选股工作台”：顶部展示合格候选、待研究、已有研究待判断和已记录个人判断的数量；大盘、持仓及个人目标分列展示，风险指标与策略说明按需展开。个人目标未设置时展开表单，保存后收起。空仓时完整展开，有持仓时默认折叠，可点击“大盘、行业与增持检查”展开。先填写计划资金、目标税前股息率、单只投入上限及预计持有年限，计划仅保存在本地，不修改实际持仓或模型评级。候选来自高股息快照中基础筛选与核心筛选均通过、年度股息率大于 4% 的股票，按年度股息率降序展示全部合格候选，不按行业数量截断。此排序不代表买入优先级。刷新清单时通过 AKShare 获取沪深300及候选对应行业的完整日线，评估120日均线及其20日方向、20日年化波动和60日最大回撤，并比较行业与大盘同期60日涨幅。中期趋势偏弱、波动超过30%、回撤超过15%或行业落后大盘超过5个百分点时，提示先等待并复核风险；这些是未经回测的研究预设，不是买卖信号。数据不足、接口失败、行业名称无法匹配及超过4个自然日的行情均提示补数据，长假期间也会保守降级。自动更新开启时，近期旧快照会单独补采缺少的大盘与行业数据；也可在建仓准备中点击“更新大盘与行业”或“直连重试”，无需重跑财务筛选。过期快照会刷新全部筛选。环境补采保留原股票行情日期、筛选更新时间和变化记录。空仓无需录入持仓；已有股票可点击“管理持仓”补录。已有持仓按数量乘快照价格统计行业市值占比，不以成本或股票数量代替；任一持仓缺少行情或行业时不展示部分权重。该占比不含现金、外部资产及拟交易金额，不等于交易后总资产仓位。行业盈利、估值和最新公告仍需人工复核。参考价格按“已实施年度每股分红 ÷ 目标股息率”计算并向下取整到分，不代表合理估值或未来收益保证。缺少年度分红时不以 TTM 替代；行情与研究保留原日期，交易前需核对券商实时行情、除息及最新公告。未找到本地研究的候选可直接预填研究配置，不会自动调用模型。

1. **自动读取已有报告**：启动后自动读取引擎结果目录（默认 `~/.tradingagents/logs`）、当前项目的 `artifacts/` 与 `reports/`，以及以前关联过的目录。从项目 `dist` 中通过 Finder 打开应用也能识别项目。每 15 秒检查新增或变更，无需逐次导入；没有变化的文件不会重复解析。其他位置的报告可在“应用设置 → 报告自动读取”中添加目录一次，之后持续检查。支持分章报告、事实附录与汇总 Markdown，原目录不修改，桌面中的个人判断和历史版本不会被覆盖。
2. **股票研究**：按名称、代码和评级检索；每次研究单独留档，同日可有多个版本。点击报告先看重点，引用按钮跳转原文；“来源事实与口径”保留数值、单位、期间和限定条件。
3. **我的判断**：按需展开表单，保存继续观察、研究意图或计划调整。与当时的报告版本关联，不改写模型评级，也不会修改实际持仓。
4. **持仓管理**：手工维护实际数量和每股成本，填写更新说明。无变化保存不新增记录，数量为 0 表示已清仓。当前不推算账户市值、收益率、现金和历史分红。
5. **应用设置**：选择服务商，填写该服务支持的快速/深度模型 ID。API Key 可写入系统凭据库，也可沿用环境变量。自定义地址只能填写不含凭据的 HTTP(S) 基础地址。CLI 的企业配置与订阅认证可继续使用。
6. **发起分析**：填写股票、日期和模型，运行独立 Python 工作进程。任务详情显示九项实际进度，包括初始化、四项并行分析、多空研究、交易计划、风险评审和报告保存；同时显示总耗时及当前阶段耗时，不估算剩余时间或完成百分比。四项分析完成后，若研究记忆尚未整理完毕，会明确显示等待状态，再进入多空研究。顶部任务栏同步显示完成项数，切换页面仍可查看。应用重启后，中断任务的耗时仅估算到最后活动时间，不计入关闭期间；旧任务缺少记录时显示耗时未知。可取消，失败可按原配置重试；只有报告成功保存并导入后才标记发布完成。完成后生成新研究版本，旧结果保留。模型调用会产生服务商费用。

分析表单的“信息截止日期”决定可使用的数据范围。研究当前情况请选择今天，包括休市日；行情使用截止日内最近交易日。选择过去日期属于历史研究：AKShare 当前财报、分红方案以及实时股吧数据没有完整历史版本，不能仅凭公告日期证明内容当时已知，因此保留为空，不把当前修订值带入历史。重试沿用原日期，需要当前研究时请改为今天。

输入 `601658` 可自动识别为“邮储银行”，并用于持仓、报告和历史记录显示。`601658`、`601658.SH`、`601658.SS` 与 `sh601658` 归为同一只股票，既有裸代码记录无需重新录入；名称匹配不会改写原始数量、成本或历史说明。内置名称表来自沪深交易所公开证券列表，2026-11-06 快照包含 5224 只股票，断网也能匹配。未覆盖的代码明确提示暂未识别，不由模型猜测名称。

窗口标题仅显示 `StockSeek`。下拉菜单使用统一主题，支持方向键、回车、Esc 和键盘跳转；持仓弹窗提供名称确认、单位和行内错误提示。备注可不填，仍以“手动维护持仓”留存操作来源；保存无变化的持仓不会新增记录，每股成本显示最多四位小数。

`⌘/Ctrl + K` 打开研究搜索；`⌘/Ctrl + N` 打开发起分析；股票页签支持左右方向键。返回会保留筛选、草稿与阅读位置。

首页只反映已有研究，尚未持续监测行情和公告。“暂时没有待查看研究”不能理解为市场没有新变化。没有对应结构化字段时，摘要显示缺失状态并提供原文，不新增模型调用替旧报告编写摘要。

## 本地 OpenAI Compatible 模型

Unsloth 等兼容服务可填写其 `/v1` 地址及 `/v1/models` 返回的完整模型 ID，访问
token 通过系统凭据库保存。若服务支持 `reasoning_effort`，可在根目录 `.env` 设置
`TRADINGAGENTS_OPENAI_REASONING_EFFORT=low`；需要关闭推理时使用服务支持的 `none`。
仅显式配置时发送此参数，不支持该参数的服务应留空。可用
`TRADINGAGENTS_MAX_TOKENS=8192` 限制每次调用的输出；过低可能截断报告。
修改后重启桌面应用。上下文窗口仍需在模型服务中单独配置：输出上限不会扩大输入容量。
单卡服务可能串行处理四项分析，长推理可能触发桌面的 15 分钟无阶段进展保护。

## 本地文件与凭据

工作空间包括：

- `workspace.sqlite3`：不可变报告快照、索引、个人判断、持仓、关联的报告目录与文件变更签名。
- `runs/<run_id>/`：每次分析的报告及状态日志；取消或失败的目录不会发布为完成报告。
- `cache/` 与 `memory/`：引擎缓存与研究记忆。
- `workspace.lock`：操作系统管理的实例锁，进程结束自动释放。

关闭应用后复制整个工作空间可备份。API Key 使用 `TradingAgents.Desktop` 系统凭据库条目，与数据库分开；不进入页面返回值或报告。新增 API Key 不写入 `.env`。源码启动会读取启动目录的 `.env`，发行包不会内嵌 `.env`，可用 `--env-file` 显式指定。

## 构建桌面应用

在目标操作系统上分别构建，不能在 macOS 上直接产出 Windows 可执行文件：

```sh
pip install ".[desktop,a-shares]" "pyinstaller>=6,<7"
python -m PyInstaller --clean --noconfirm desktop/desktop.spec
```

- macOS：`dist/StockSeek.app`，使用系统 WKWebView。本机产物为 Apple Silicon；Intel 需在对应环境构建验证。
- Windows x64：`dist/StockSeek/StockSeek.exe`。分发整个 `StockSeek` 文件夹，包含独立后台工作程序和 Python 运行时。需已安装 Microsoft Edge WebView2 Runtime；固定使用现代 Edge，不回退到 IE。
- 两个平台都直接加载本地静态资源，无需额外启动 HTTP 后台、外部数据库或安装 Python。
- `.github/workflows/desktop.yml` 提供手动及 PR 构建，上传产物但不自动发布。正式发行签名与 macOS 公证需要相应证书；当前是未公证的开发构建。

## 验收进程清理修复（2026-11-06）

旧原生验收脚本在断言通过后调用 `sys.exit`，仍可能等待 WebView 后端的非守护线程，导致多个 Python 验收实例留在桌面。现在原生验收需要 `--native` 显式开启，并在清理完成后结束整个测试进程；超时机制也负责回收。`tests/test_desktop_smoke_lifecycle.py` 覆盖线程未退出和缺少显式开启标记两种情况。

界面改为更紧凑的工具栏、研究列表与阅读分栏，减少教学说明、空卡片和重复提示；保留可展开的数据缺口与原文入口。新增统一 SVG 导航图标及独立应用图标。

## 自动报告库修复（2026-11-06）

启动与报告目录检查在后台进行。桌面自身 `runs/` 的完成结果仍由任务成功状态发布，自动检查不会把取消或未完成任务中的文件误发布。外部文件刚修改时等待短暂稳定期再读取；格式异常的报告单独记录并重试，不会阻塞其他报告。

如果把应用第一次直接移到 `/Applications` 等独立目录，且引擎使用非默认位置，应用不能推断任意磁盘路径；可在设置里关联项目报告目录一次。已经识别或关联的目录会保留，后续移动应用无需重复配置。

## 分维度研究速览（2026-11-06）

侧栏统一为今日关注、股票研究、持仓管理、历史记录，底部为应用设置；页面标题与顶部位置同步。

今日关注左侧展示股票、模型评级、两行结论摘录、首次/更新提示与日期，便于在切换研究前浏览观点。右侧明确标注“模型观点”与分析日期，避免混淆个人判断与实时行情。选中研究后，右侧在剩余窗口高度内显示总体结论、技术面/基本面/消息面/情绪面重点和后续关注。中部内容可滚动，顶部股票身份与底部“打开研究 / 记录判断”操作保持可见；窗口宽度不超过 900px 时使用纵向布局，并取消预览区的独立滚动。工作页面随窗口铺开，今日关注列表限制为 280–380px，其余宽度留给研究速览；报告正文和表单仍保留阅读宽度。

各维度从明确的摘要/结论标签或结构化报告中提取原文，点击重点可定位原始段落。风险段落会保留可获得的趋势背景或支撑因素。缺少独立章节、摘要未提取、未评估、数据不足与校验失败分别显示；缺失不能解释成没有风险。长段落仅限制视觉行数，保留全部条件、否定及口径限定供原文查阅，不重新调用模型、不生成新的经济判断。

今日关注默认突出研究结论、执行方式、执行条件与失效条件；期限、事件窗口和补充依据按需展开。各维度仅默认显示首条原文重点，宽屏以两列展示，补充观点可展开查看。后续关注与术语折叠保留，数据不足与需复核状态始终显示。展示顺序不代表新的投资判断，完整条件仍以原报告为准。

速览在读取时由已有快照派生，旧报告无需重新导入，也不会因此新增研究版本或覆盖个人记录。
# 高股息候选

界面采用中性暗色、低饱和强调色和紧凑表格。高股息看板顶部展示快照时间和三个可切换的数量卡片：红利低波精选、股息率 >4%、精选待核验。卡片数量对应整个快照，列表标题数量对应当前筛选结果。搜索、行业及自选筛选常驻；风险窗口和数值门槛收纳在“更多筛选”，应用后保持展开并显示“已启用”，重置后收起。表格支持点击列标题排序，滚动时保留表头和股票列；窄窗口在表格内横向滚动。自选跟踪、变化、其他核验记录和口径说明集中在列表下方，完整依据仍在侧栏查看。

桌面“高股息”页支持后台刷新、进度反馈、取消和失败重试，也可读取当前工作空间中的已有快照。默认展示红利低波精选，主入口为精选、股息率 >4% 与精选待核验；其他基础核验记录折叠展示。表格直接显示未通过或待补充的条件，点击“核验依据”打开侧栏，可查看完整核验、年度税前已实施分红金额、计算价格及行情时间，按 Escape 或关闭按钮返回表格。备用分红来源成功获取后单独说明，原始接口提示保留在可展开的采集记录中。支持全 A 股大盘候选发现、股息率及风险指标排序、近 1 年/3 年低波阈值筛选，不限制央国企或行业前三。抓取命令、覆盖限制和筛选口径见 [高股息筛选说明](dividend-screen.md)。

后台研究连续 15 分钟未收到阶段进展或实际模型、工具调用的起止事件，或总运行超过 60 分钟时，会停止本次工作进程并显示超时失败，可按原配置重试；超时任务不发布报告。此限制包含数据获取与模型推理的等待时间，不使用定时心跳延长等待。

每次研究的 `runs/<run_id>/diagnostics.jsonl` 实时记录模型与工具调用的起止时间、调用 ID、所属图节点、耗时、错误类型，以及多空和风险讨论的实际轮次进展、任务退出状态。模型响应另记录正文字符数、工具调用数、结束原因及服务端提供的输入/输出 token 计数，可区分空回复、输出截断与格式错误。异常另记录代码文件名、函数和行号，便于定位；不记录凭据、提示词、工具入参、模型回答或异常消息。中断时可根据缺少结束事件的调用定位最后等待的位置；单次模型调用内部的 SDK 重试不单独显示。历史任务无法补回这些日志。

GLM-5.3 / GLM-5.3-flash 未指定思考强度时默认使用 `low`，避免服务端默认的最大思考强度占用有限的输出预算；仍可通过 `TRADINGAGENTS_GLM_REASONING_EFFORT=high` 或 `max` 显式调整。报告生成和格式修复优先使用服务商的结构化输出能力，随后仍严格检查完整 JSON、报告结构及原始证据引用；结构化输出不代表事实已通过核验。

关注与刷新对比：候选可一键加入“我的自选”并保存个人备注，也可勾选“只看自选”。这些内容保存在当前本地工作空间，退出筛选不会删除，也不会改动实际持仓。页面显示最后成功更新时间和行情日期；刷新失败或取消保留原清单及变化记录。成功刷新后，比较同范围、同精选规则的上次快照，显示精选进出、年度股息率跨过 4% 门槛及同年度每股分红下调；数据缺失、采集范围或口径改变不能解释为财务恶化。首次刷新或旧快照不可比较时先建立基线。这里只比较刷新快照，不执行自动交易。

覆盖对账：采集时分别读取沪市主板、科创板、深市和北交所名单，与行情代码核对。任一名单接口失败或疑似不完整，页面标记“市场覆盖未确认”，展示已取得的部分名单数量。名单中缺行情的股票仍进入待核验范围；不能把缺数据当成不符合条件。旧快照没有对账记录时也不宣称覆盖完整。

每日更新：在“更新与连接”中开启或关闭，设置保存在当前工作空间。完成首次手动采集后，应用打开期间每分钟检查一次；按上海时间 18:00 作为更新基准。筛选快照保存 AKShare 交易日历，在日历覆盖范围内回溯到最近交易日；日历缺失或超出覆盖范围时回退到工作日规则，不推断未知日期为休市。旧快照、名单覆盖未确认或价格/年度分红缺失时，间隔至少一小时补采，每个自然日最多尝试三次；当天取消后停止自动尝试。退出应用后不运行，更新过程不触发付费模型研究，失败或取消仍保留上次成功清单。

高股息看板顶部集中显示市场覆盖、精选待核验数、年度股息率缺失数和交易日历覆盖范围，并提前展示本次快照变化。筛选与排序使用年度已实施税前股息率，须严格大于 4%；TTM 仅供参考。缺失不视为零，待核验不视为已满足精选条件。每只股票的分红年度、每股金额、行情时间及来源可在“核验依据”中查看。

研究后的操作：建仓准备中已有研究的候选提供“阅读结论与条件”和“记录个人计划”。先核对报告的执行条件、反向证据及失效条件，再在个人判断中记录等待条件、资金上限、放弃条件或复查时间。报告摘要也提供下一步入口。保存后可返回今日关注；最近记录若对应当前报告版本，会显示在候选行，旧版本判断不会标记为本版判断。需要等待时不必录入持仓，实际成交后再到持仓管理录入数量与成本。研究完成、模型评级及目标股息对应价格均不表示买入条件已触发。
