# 高股息与低波筛选

桌面“高股息”页点击“刷新筛选”，或从项目根目录运行：

```powershell
$env:PYTHONUTF8='1'
.\.venv\Scripts\python.exe -m tradingagents.dataflows.dividend_screen --data-dir data/desktop --direct
```

`--direct` 仅让本轮公开数据请求绕过环境代理。优先从 AkShare 东方财富全 A 股行情发现候选；失败、重复代码或明显不完整时改用腾讯 `stock_zh_a_spot_tx`，两者均失败则保留旧快照。排除总市值不足 500 亿元的股票，再逐只核验。市值缺失者保留核验，不因缺失而静默排除。已取消央国企实际控制与行业前三条件；旧资格证据文件不再参与筛选，`--require-qualifications` 参数已移除；旧快照仍可读取。

支持 `--codes 600941 601088` 在全市场发现后限定核验子集（仍受市值门槛约束）。子集会替换目标目录快照并明确标识，试跑应使用 `--data-dir output/dividend-trial`，避免覆盖日常清单。

## 覆盖、刷新和发布

页面显示扫描数量、市值排除数量、核验数量、完整低波指标数量及有接口错误的候选数量。旧版固定候选快照仍可读取，但提示需要刷新。每次刷新会获取沪市主板、科创板、深市与北交所名册，与行情代码交叉核对；名册中的行情缺失股票保留为候选，不能因市值未知被排除。任一板块名册失败时标记覆盖未确认，行情遗漏和额外代码分别记录在 `discovery.roster`。全市场返回不足 4000 只时拒绝发布，防止明显分页缺失；名册对账成功也不代表个股财务与分红数据已完整。

后台先发现候选，再显示动态核验总数。逐只先采集分红：确认年度股息率 ≤4% 者保留记录并停止采集行业、财报和低波数据，明确注明未继续采集；股息率未知者继续核验，不静默排除。页面另列因股息门槛跳过的数量，不将其描述为接口失败。全市场比旧版 16 只耗时更长；每个接口子进程最多 50 秒并重试一次，并发核验 3 只，可切换页面或取消。无付费模型调用。关闭应用停止本轮抓取，重启标记中断。已打开旧版本桌面需重启以加载更新。

结果先写入 `dividend-runs/`，成功退出后校验候选清单与发现清单、计数一致才发布。取消、失败、候选缺项或所有候选均有供应商错误时保留旧快照。单股缺失会明确显示。财报缓存有效期 24 小时，行情及历史价格缓存另按当天区分；失效缓存不回退冒充新数据。错误分别记录空表、超时、接口进程异常、格式无效或启动失败；空表不等于没有分红，不展示原始进程错误以免泄露环境信息。

生成 `dividend-screen.json`、Markdown 清单及 `dividend-cache/`，默认 `data/desktop/` 被 Git 忽略。命令行生成后可点击“读取最新快照”；数据目录需与桌面一致。损坏快照显示错误并保留页面已加载的有效结果。

## 列表操作

默认展示“红利低波精选”。“股息率 >4%”宽候选池严格排除恰好 4%、低于 4% 及股息率缺失者；这仅表示满足股息门槛，现金流等条件仍以核验状态为准。最近完整年度税前股息率默认降序。股息率、市值、静态 PE、波动率、最大回撤、成交额均支持表头升降序；缺失始终置后，同值按代码排序。切换状态或读取快照保留排序。“全部核验记录”与状态分类用于排查未通过或缺失数据，不等于高股息筛选结果。

可按股票代码/名称、行业、最低股息率、最高年化波动率、最高最大回撤、最低日均成交额筛选，并切换近 1 年/3 年风险窗口。点击“应用筛选”生效，“重置条件”清除附加筛选，保留当前候选池。有阈值时，相关指标缺失者不会混入匹配结果。量化通过仅指基础股息与财务规则；精选视图始终执行固定低波门槛，附加条件可进一步收窄；宽候选池未设置阈值不代表低波通过。展开“查看依据”核对规则、缺失项、行情日期及来源。

## 红利低波精选

默认精选要求基础量化核验通过，并满足以下研究阈值：

- 最近完整年度每股分红 / 同年度基本 EPS 大于 0 且不超过 80%。这只是每股派息率估计，不等于现金分红总额 / 归母净利润；EPS 缺失、来源冲突或近期送转影响可比性时待核验。
- 近三个完整年度每股分红均为正，按统一股份口径比较，每年降幅不超过 20%；缺年末分配实施记录则待核验。
- 近一年、三年年化波动率均不超过 25%；最大回撤分别不超过 25%、35%；20 交易日日均成交额至少 1 亿元。风险行情必须不晚于筛选日且相距不超过四个自然日。

页面分别保留精选、精选待核验、股息率 >4%、基础通过、基础待核验、基础未通过及全部记录。已知不符合精选规则者不进入“精选待核验”。展开依据可同时查看精选与基础规则。缺项不补零，也不为凑足数量放宽门槛。

旧快照读取时，可从原采集时间、接口和股票代码均匹配的本地财报缓存补算派息率与累计现金流规则；只读投影，不联网、不改写原快照，页面保留原采集日期。无法匹配缓存的记录保留原财务核验并注明覆盖数量，新增缺项待核验。

上述阈值尚未回测，不代表已验证的超额收益策略。审计意见、最新季度恶化、特殊分红与金融行业监管指标尚未完整自动检查，精选不是买入建议。

## 数据口径

- 东方财富或腾讯全 A 行情用于发现和初步市值筛选，保存实际使用的接口及备用源标志；腾讯发现接口的 `zsz` 单位为亿元，转为元后与东方财富使用同一门槛。东方财富个股信息用于行业分类；腾讯公开行情提供核验股价、时间和总市值（亿元）。A/H 公司使用供应商市值口径。报表人民币元，每 10 股派息换算为每股。
- 默认门槛与排序使用最近完整年度（筛选年份减一）税前股息率：按报告期归属累计该年度已实施现金分红，除以行情价格。必须有该年度年末分配实施记录；年末记录缺失标待核验，不回退到更早年份。已实施送股/转增按当前股数折算：每笔每股现金除以同期及后续送转因子的连乘（1 + 每10股送转数/10），再求和；重复记录不重复累加，冲突记录标待核验。该折算仅覆盖接口所含已实施送转，不自动处理配股等其他股本变化。年度口径不包含其他年度中期分红，特别分红仍可能影响可持续性。旧快照在读取时按保存明细重算，不改写原文件。
- 税前 TTM 股息率仅供参考，不作为默认门槛：最近一个周年内按除息日累计已实施现金分红除以当前价，不计未来公告和预案。每笔现金采用相同送转折算规则。特别分红计入，不代表可持续收益。
- AkShare 的 `stock_fhps_em(date=报告期)` 和 `stock_fhps_detail_em(symbol=代码)` 均直接返回“现金分红-股息率”。该字段附属于具体报告期/分红记录，官方文档未说明其分母价格时点与滚动年度口径，不能直接当作当前 TTM 股息率或把多个百分比相加。本项目已使用后者获取分红明细，再按统一价格分别计算年度及 TTM 股息率。
- 分红日期、金额、送转比例缺失或无效不当作零分红。仅当报告期与除息日均可确认早于近五个完整年度的起点，旧记录缺口才不影响当前核验；无法确定期间或最近支付的旧年度分红仍须核验。送转比例空值仅在完整方案明确纯现金分红且金额一致时认可。现金字段空值仅在方案完整明确纯送股/转增且数量与送转字段一致时解析为零，原方案及解析依据保留；其他空值仍未知。差异化分红等复杂方案不自动猜测。报表须有不早于报告期的有效公告日期。
- 基础门槛：股息率严格 >4%、市值 ≥500 亿元、连续 5 个完整年度分红、最近年报静态 PE 在 (0,20]；近 3 年归母利润为正且最近年降幅 ≤30%；近三年经营现金流各年为正、三年累计覆盖累计合并净利润；资产负债率 ≤75%。这些是研究假设，不保证不爆雷。
- 自由现金流代理值为经营现金流减购建长期资产现金支出，保留在 JSON，不作硬门槛。银行、保险、证券及多元金融跳过普通企业现金流、负债率规则，改用下述行业核验。行业缺失者须复核适用性。
- 低波使用 AkShare 前复权日收盘价，排除筛选当天未完成 K 线。年化波动率为每日简单收益率样本标准差 ×√252；最大回撤为窗口运行最高价至后续最低价的最大跌幅，显示正百分数。近 1 年/3 年分别至少 200/600 个日收益，起点需在周年日 14 天内；不足标缺失。近 20 交易日日均成交额单位亿元，缺失不补零。
- 前复权价格并非税后分红再投资总收益；不计算 Beta，历史低波不保证未来低风险。行情超过 4 个自然日标待核验，长假、停牌需复核。当前是现时筛选工具，不支持历史时点回测。
- 供应商无可用性保证；审计意见、质押、未来分红和最新季度恶化未完整检查。清单用于研究，不是买入指令。

## 金融行业自动核验

刷新时通过 AkShare `stock_financial_analysis_indicator_em(symbol="600036.SH", indicator="按报告期")` 获取原始行业字段，沿用独立子进程超时、重试和 24 小时缓存。每股保存接口、抓取时间、报告期、公告日、原字段名与单位；展开“查看依据”可见数值、阈值及日期。旧快照不联网补数，需刷新后应用新规则。

- 银行：不良贷款率 `NONPERLOAN` ≤2%、拨备覆盖率 `BLDKBBL` ≥150%、核心一级资本充足率 `HXYJBCZL` ≥9%、资本充足率 `NEWCAPITALADER` ≥12%。四项均为研究筛选预设，不代替各银行差异化的监管要求，不代表完整资产质量审查。
- 证券：风险覆盖率 `RISK_COVERAGE` ≥120%、资本杠杆率 `CAPITAL_LEVERAGE_RATIO` ≥9.6%、流动性覆盖率 `LIQUIDITY_COVERAGE_RATIO` ≥120%、净稳定资金率 `NET_FUNDING_RATIO` ≥120%。参考[证监会风险控制指标管理办法](https://www.csrc.gov.cn/csrc/c106256/c1653957/content.shtml)的四项最低标准及 120% 预警比例；本软件仅将其作为筛选缓冲，不能认定全部监管要求合格，也未完整核验自营资产质量。
- 银行和证券四项必须来自同一期最新已公告报告，报告距筛选日不超过 270 天；缺项不拼接更早报告来凑齐。报告期、公告日和可用更新日均不得晚于筛选日，公告日必须不早于报告期。已知不达标为未通过，缺失、非有限值、过期为待核验。
- 保险：采集 `SOLVENCY_AR`（偿付能力充足率）、`TOTAL_ROI`（总投资收益率）、`NET_ROI`（净投资收益率）作为参考；季度可能未披露，允许展示 270 天内最近有值的期间，但逐字段明确其报告期和公告日，不参与合格判定。接口没有明确偿付能力的核心/综合及集团/子公司口径，也没有可对应主体的风险综合评级和完整投资资产质量，因此保险仍待核验。不会把一个偿付能力百分比当成全部保险条件已补齐。
- 多元金融：业务及监管主体不同，继续待核验，不套用证券规则。

## 分红解析与备用来源

分红核验会隔离五年核验窗口之前的历史记录：报告期及至少一个实施/公告日期均须早于窗口，任一近期日期均阻止隔离。缺少日期而无法确定期间的记录仍待核验；原始记录保留在来源缓存，隔离依据记录在 `dividend_excluded_history`。现金方案明确列出大小股东差异分红时，使用中小股东税前每十股金额，保留来源金额与解析依据；无法可靠识别的差异方案不会使用公司加权金额代替。

东方财富分红接口失败时，尝试 AkShare `stock_dividend_cninfo` 巨潮实施分红接口，保留来源及主接口错误。备用源成功时允许发布并保留主源错误提示；所有候选的分红来源均失败时保留旧清单。两份来源不拼接，以免重复计算；备用接口失败、字段不足或期间无法匹配时仍显示待核验，不会补零或默认通过。

## 官方公告补充与上市历史

工作空间可保存 `dividend-official-evidence.json`，供桌面读取和后续筛选复用。命令行通过 `--official-evidence` 指定其他位置。此文件是人工核对公告后的补充证据，不是自动抓取或自动审计结果；真实证据保存在被 Git 忽略的本地工作空间。

格式为 `schema_version: 1` 及 `records` 数组。每项必须包含六位股票代码 `code`、上市主体全称 `entity`、`scope: listed_entity`、报告期 `report_date`、披露日 `notice_date`、HTTPS 公告地址 `source_url`、从 1 起算的 PDF 页码 `page` 和 `fields`。比例字段必须注明 `unit: %`。支持银行及证券现有指标，以及 `CORE_SOLVENCY`、`COMPREHENSIVE_SOLVENCY`、`RISK_RATING`、`A_LISTING_DATE`。应由核对者确认公告来源和上市主体，格式校验不能证明来源真实性。

银行和证券仅补同一期最新、有效报告的缺失值；接口值与公告冲突时继续待核验，不择取更有利的值。保险单列核心、综合偿付能力和风险综合评级，逐项保留主体、期间、披露日期、来源及页码；评级期间可以与偿付能力期间不同，但不会冒充后续季度评级。完整投资资产质量仍须单独核验，不能以偿付能力或投资收益率代替。

晚于筛选日的公告不应用；过期报告不回填。格式错误会在桌面明确提示。补充证据在读取快照时投影，不覆盖原始快照，也不更新原采集时间；移除补充文件后恢复原始接口核验结果。刷新任务同样读取该文件，因此未来报告不会被旧期间证据自动补齐。

已确认 A 股上市不足三年的公司，精选明确显示“上市历史不足”，不再将三年低波样本缺失仅表述为接口待核验；H 股历史不能替代 A 股样本。基础股息条件若缺少资料，仍保留待核验，二者分别展示。

刷新进度包含因股息率不足而提前结束核验的候选；提前排除原因仍保存在 `collection_stage` 字段。
