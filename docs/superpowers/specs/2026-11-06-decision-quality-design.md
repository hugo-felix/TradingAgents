# 决策质量修复

依据：用户已认可 600941 复盘并要求“修复”。实施范围为已发现的输入、决策和展示缺陷，不改变历史评级，不以单日涨跌训练固定方向。

## 方案

沿用现有数据路由、事实引用契约、桌面速览，不增加服务或常驻 MCP。仅修改提示词无法保证决策字段完整；重建分析引擎成本过高。本次选择补齐现有契约与数据入口。

1. A 股新闻预取增加独立事件候选检索：回看45天，仍严格截止分析日。公司相关新闻先按事件线索筛选，再按条数限流，避免较早预告被普通近闻挤出。保留标题、发布日期、原文和链接；候选不是已确认未来日历，分析师必须核实举行日期、主体及是否落在未来窗口。没有候选或接口失败均标注覆盖不足，不能推论没有催化。不得获取预测日之后发布的报道。
2. 新的 A 股最终决策必须有独立计划对象：配置期限、执行模式、执行条件、计划有效期、失效条件、最强反向证据、已知事件窗口、市场/板块比较。空字段或缺对象只能修复一次，再失败则 REVIEW。没有明确价格或催化证据时写未核实、等待条件；不得制造价位和日期。原始事实数值继续由代码渲染；新生成流程对可识别的带单位数值检查其数值和单位是否与引用的事实一致，防止 -1454.6 万户变成 -145.5 万户。该检查不验证经济推理、未标注单位的数字或所有自然语言单位，不将引用合法视为经济结论正确。
3. 下游共同推理规则要求区分季度和累计、采购和费用确认、关注度和方向、配置和次日预测；同源多智能体不是独立验证。研究经理与最终经理都直接看到原始四维报告，必须解释与其判断的差异；不能仅依赖辩论摘要。交易员保留有条件执行的边界。
4. 速览在总体结论下展示配置期限、执行条件、有效期、失效条件和事件窗口，原文可点击。旧报告仅提取显式标签、标题或同段明确的“执行上”等标记，保留整段条件与限定，未知字段显示未提供；不回写快照、不进行额外模型推断。新决策文本在完整报告和导出中同样保留字段。
