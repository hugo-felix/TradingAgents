# 研踪桌面工作台实施计划

> 按已确认的 `docs/desktop-research-proposal.md` 执行，在当前会话逐项完成并验证。

**Goal:** 提供真实报告、重点摘要、个人记录与后台分析组成的 macOS/Windows 桌面应用。

**Architecture:** pywebview 白名单桥连接本地报告、任务和 SQLite 数据服务。现有 TradingAgents 引擎在独立进程运行；前端无需构建工具，静态资源随 Python 包分发。

**Tech Stack:** Python 3.11+、pywebview、SQLite、原生 HTML/CSS/JavaScript、PyInstaller。
